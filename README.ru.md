# dsh-model-price

[English](README.md) | **Русский**

Цены за API по моделям, баланс кошелька и живой расход сессии для [DeepSeek Harness](https://github.com/deepseek-ai).

Плагин добавляет компактную строку под окном ввода — `Сессия: $0.0123 · Кошелёк: $12.34 · Peak` — и секцию **Модели и цены** в настройках, где задаётся стоимость каждого миллиона токенов в USD или CNY отдельно для Peak и Off-Peak.

## Возможности

- **Таблица цен по моделям** — ввод (cache miss), вывод, кэш-хит и запись кэша, каждая с ценой Peak и Off-Peak. Пустой кэш-хит считается по цене ввода, пустая запись кэша бесплатна, пустой Off-Peak повторяет Peak.
- **Две валюты** — цена модели вводится в USD или CNY, отображение идёт в одной выбранной валюте по ручному курсу CNY/USD. Баланс кошелька конвертируется так же, исходные суммы видны в поповере.
- **Кошелёк** — реальный баланс аккаунта DeepSeek и бонусные кошельки. Если аккаунт недоступен, можно задать локальный бюджет как резерв. Иконка глаза скрывает сумму.
- **Живой расход сессии** — токены берутся из журнала сессии (`assistant/message`), повторы не задваиваются, строка обновляется во время работы модели. Дочерние сессии субагентов и workflow учитываются и показываются отдельно.
- **Peak / Off-Peak** — бейдж следует редактируемому окну в UTC (по умолчанию у DeepSeek 16:30–00:30). Peak оранжевый, Off-Peak зелёный; при расчёте берётся цена соответствующей колонки.
- **Каталог моделей** — одна кнопка подгружает все модели из **Настройки → Models**, дубликаты пропускаются, список сворачивается.
- **Локализация** — 9 языков и автоматическое обнаружение новых файлов локализации (см. ниже).

## Требования

- DeepSeek Harness **0.2.0** или новее (профиль Web/Desktop).
- Встроенный в DSH Node.js (22.5+). Сборка не нужна, зависимостей нет.

## Установка

### Вариант 1 — Add Plugin (рекомендуется)

1. Откройте **Настройки → Плагины → Add plugin**.
2. Вставьте имя пакета, адрес GitHub-репозитория или абсолютный путь к папке:

   ```
   dsh-model-price
   ```

   ```
   github:itsbuyru-bit/dsh-model-price
   ```

   ```
   https://github.com/itsbuyru-bit/dsh-model-price
   ```

   ```
   /path/to/dsh-model-price
   ```

3. Установите, перезапустите DeepSeek Harness и обновите страницу.

> Имя из npm сработает после публикации пакета в реестр (см. *Публикация*); варианты с GitHub работают сразу для публичного репозитория.

### Вариант 2 — CLI

```sh
dsh plugin --profile <your-profile> add dsh-model-price
dsh plugin --profile <your-profile> add github:itsbuyru-bit/dsh-model-price
```

Профиль `desktop` принадлежит Electron-приложению, и CLI отказывается в него писать — для него используйте **Add Plugin** в интерфейсе.

### Вариант 3 — локальная разработка

```sh
git clone https://github.com/itsbuyru-bit/dsh-model-price.git
dsh plugin --profile <your-profile> add link:/absolute/path/to/dsh-model-price
```

Изменения Host-половины требуют переустановки бандла, клиентской — только обновления страницы.

## Использование

1. Откройте **Настройки → Модели и цены**.
2. Нажмите **Загрузить модели из Models**, чтобы подтянуть модели, настроенные в харнессе, или добавьте модель вручную (провайдер + id).
3. Разверните строку модели и заполните цены Peak / Off-Peak за 1M токенов.
4. Нажмите **Применить** внизу блока. Строка под вводом и поповер обновятся сразу.

Строка показывает `Сессия: … · Кошелёк: … · Peak`. По клику — состав токенов, стоимость по моделям, разбивка кошелька и общий итог; иконка глаза скрывает кошелёк.

Цены применяются ретроактивно: правка ставки пересчитывает всю видимую историю, о чём и написано в поповере. Если для модели цена не задана, итог сессии показывает `?`, а модель попадает в список «цена не задана», а не считается молчаливым нулём.

Данные лежат в `~/.dsh/api-spend/` (`config.json`, `totals.json`). Баланс запрашивается у аккаунта DeepSeek; курс вводится вручную, сетевых запросов за курсом нет.

## Как добавить язык

Файлы локализации лежат в `locale/` и называются по BCP 47 с субтегом региона или письменности — `en-US.json`, `ru-RU.json`, `zh-CN.json`, `pt-BR.json`, `de-DE.json`, … Файл без субтега (`en.json`) игнорируется.

Каждый файл самодостаточен:

```json
{
  "locale": "it-IT",
  "name": "Italiano",
  "meta": { "title": "Model Price", "description": "…" },
  "strings": {
    "session": "Sessione",
    "wallet": "Portafoglio",
    "…": "…"
  }
}
```

1. Скопируйте `locale/en-US.json` в `locale/<tag>.json`.
2. Переведите все значения в `strings` и `meta.description`.
3. Сохраните ключи, подстановки `{n}` и `{rate}` и не переводите: `Peak`, `Off-Peak`, `USD`, `CNY`, `DSH`, `DeepSeek`, `API`, `cache miss/hit/write`, `Model Price` (имя в инвентаре).
4. `settingsTitle` / `settingsNav` — заголовок страницы и подпись в навигации, их нужно переводить (`Models & prices`, `Модели и цены`, …).
5. Укажите `"locale"` тем же тегом, что имя файла, а `"name"` — название языка на нём самом.

Host перечитывает `locale/` при каждом запросе, поэтому новый файл подхватывается без перезапуска: откройте **Настройки → Модели и цены** (секция делает ре-скан и обновляет клиент) или обновите страницу. Отсутствующие ключи берутся из `en-US`, затем показывается имя ключа.

Языки в комплекте:

| Файл | Язык |
|---|---|
| `locale/en-US.json` | English (US) |
| `locale/ru-RU.json` | Русский |
| `locale/zh-CN.json` | 简体中文 |
| `locale/ja-JP.json` | 日本語 |
| `locale/ko-KR.json` | 한국어 |
| `locale/es-ES.json` | Español |
| `locale/pt-BR.json` | Português (Brasil) |
| `locale/de-DE.json` | Deutsch |
| `locale/fr-FR.json` | Français |

## Разработка

```sh
git clone https://github.com/itsbuyru-bit/dsh-model-price.git
cd dsh-model-price
node scripts/check.mjs   # синтаксис, манифест и совпадение ключей локалей
```

Плагин — обычный JavaScript: `index.js` — Host-половина, `client.js` — браузерная, `cordis.patch.yml` вставляет строку плагина. Сборки нет.

```sh
npm publish
```
