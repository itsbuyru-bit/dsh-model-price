# Support

- **Bug reports and feature requests** — open an
  [issue](https://github.com/itsbuyru-bit/dsh-model-price/issues) using the
  templates.
- **Questions about a price, a token count or a wallet number** — include the
  model route (`provider/model`), the DeepSeek Harness version, and whether the
  provider reported usage for that step.
- **Translations** — see the *Adding a language* section of the
  [README](README.md); pull requests with a new `locale/<tag>.json` are welcome.
- **Security issues** — do not open a public issue; use
  [SECURITY.md](SECURITY.md).

Before opening an issue, run `node scripts/check.mjs` and include its last lines.
It catches most manifest and locale problems in one command.
