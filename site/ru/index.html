Плагин для DeepSeek Harness

Знайте, сколько стоит каждый токен.

Цены API по моделям в USD или CNY, баланс кошелька и живой расход сессии — одной тихой строкой под окном ввода, по журналу, который уже есть.

Установка с GitHub спецификация плагина
$ github:itsbuyru-bit/dsh-model-price

Вставьте в Настройки → Плагины → Add plugin, перезапустите DeepSeek Harness и обновите страницу. Пакета в npm нет.

Добавить в Harness GitHub

Скриншоты

Каждая цифра — в один клик.

Строка не мешает, пока не нужна. Откройте поповер: состав токенов, стоимость по моделям, разбивка кошелька и общий итог — а затем задайте ставки, из которых они получаются.

Возможности

Цены, которые совпадают с тем, как вы платите.

Всё строится на журнале сессии. Ничего не оценивается «на глаз», не переписывается и не блокируется.

Цены по моделям, Peak и Off-Peak

Input, output, cache hit и cache write — у каждого ставка Peak и Off-Peak. Колонку выбирают редактируемые окна и дни недели в UTC; у DeepSeek Peak — 01:00–04:00 и 06:00–10:00, пн–пт, кроме праздников Китая.

Две валюты и ручной курс

Цены в USD или CNY, отображение в любой из них и конвертация по ручному курсу из настроек. Сервис курсов не вызывается.

Кошелёк и бонусные кошельки

Реальный баланс аккаунта DeepSeek и бонусные кошельки с разбивкой в поповере. Если аккаунт недоступен, подставится локальный бюджет.

Живой расход сессии

Обновляется во время работы модели. Повторы не задваиваются, шаги без usage показываются, а не додумываются; модель без цены даёт ?.

Синхронизация с Settings → Models

Одна кнопка повторяет модели, привязанные в Settings → Models. Провайдер с пустым списком не даёт ничего, а убранная модель исчезает из таблицы цен вместе со своими ценами.

Девять языков

Английский, русский, китайский, японский, корейский, испанский, португальский, немецкий и французский — локали находятся автоматически и переключаются отдельно от Harness.

Как это работает

Три шага от установки до цифр.

  1. 01

    Добавьте модели

    Откройте Настройки → Модели и цены и нажмите Загрузить модели из Models либо добавьте провайдера и id модели вручную.

  2. 02

    Задайте цены

    Разверните строку и заполните цены input, output, cache hit и cache write за миллион токенов для Peak и Off-Peak, затем нажмите Применить.

  3. 03

    Читайте строку

    Расход сессии, кошелёк и текущий тариф — под окном ввода. Клик открывает токены, стоимость по моделям и общий итог.

Ваши данные остаются локально

Всё, что пишет плагин, лежит в ~/.dsh/api-spend/: цены, валюта, курс и счётчики токенов. Расход сессии читается через проекцию Harness и не изменяется. Наружу уходят только запрос баланса, который делает сам Harness, и необязательная проверка обновлений — её можно отключить. Ни аналитики, ни телеметрии.

Языки

Девять локалей, один плагин.

Язык плагина не зависит от Harness и переопределяется отдельно. Недостающие ключи берутся из английского по одному.
