DeepSeek Harness plugin

Know what every token costs.

Per-model API prices in USD or CNY, your wallet balance and live session spend — one quiet line under the composer, priced from the session log you already have.

Install from GitHub plugin spec
$ github:itsbuyru-bit/dsh-model-price

Paste it in Settings → Plugins → Add plugin, then restart DeepSeek Harness and refresh the page. There is no npm package.

Features

Pricing that matches how you actually pay.

Built from the durable session log. Nothing is estimated, nothing is rewritten and nothing blocks a request.

Per-model pricing, Peak and Off-Peak

Input, output, cache hit and cache write, each with a Peak and an Off-Peak rate. An editable UTC window picks the column — DeepSeek’s default is 16:30–00:30.

Two currencies, one manual rate

Enter prices in USD or CNY, display in either and convert with a manual FX rate stored in your settings. No exchange-rate service is ever called.

Wallet with bonus wallets

The real DeepSeek account balance plus bonus wallets, split in the popover. When the account is unavailable, a local budget can stand in.

Live session cost

Updates while the model works. Retried steps are de-duplicated, aborted steps without usage are reported rather than guessed, and unpriced models show ?.

Sync from Settings → Models

One click mirrors the models bound in Settings → Models. A provider with an empty list contributes nothing, and a model removed there leaves the price table with its prices.

Nine languages

English, Russian, Chinese, Japanese, Korean, Spanish, Portuguese, German and French — discovered from locale files and switchable independently of Harness.

How it works

Three steps from install to insight.

  1. 01

    Add your models

    Open Settings → Models & prices and press Load models from Models, or add a provider and model id by hand.

  2. 02

    Set your prices

    Expand a row and fill the input, output, cache-hit and cache-write prices per million tokens for Peak and Off-Peak, then press Apply.

  3. 03

    Read the line

    Session cost, wallet and the current tariff sit under the composer. Click the line for tokens, per-model cost and the all-time total.

Your usage stays local

Everything the plugin writes lives in ~/.dsh/api-spend/: prices, currency, FX rate and token totals. Session usage is read through a Harness projection and never modified. The only outbound calls are the account balance made by Harness itself and the optional update check — which you can switch off. No analytics, no telemetry.

Languages

Nine locales, one plugin.

The plugin language is independent of Harness and can be overridden per plugin. Missing keys fall back to English, key by key.
